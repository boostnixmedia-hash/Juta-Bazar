# জুতার বাজার / JUTAR BAZAR

Premium online shoe shop. PHP 8 + SQLite, no database setup needed.

- **Live demo (no password, nothing saves):** open the GitHub Pages link for this repo (`docs/` folder). The admin demo is at `admin.html`.
- **Real site:** download this repo as a ZIP, upload everything except the `docs/` folder to cPanel `public_html` and extract it. Open `yourdomain.com/admin` and set your admin password on the first visit.

## Features
- English by default, one-tap switch to বাংলা (remembered for each visitor)
- 5 collections, product pages with size guide, "only X left" badge, recently viewed
- Cart, cash-on-delivery checkout, order tracking, WhatsApp order + popup
- Admin panel in Bangla: dashboard with sales chart, orders, invoice, CSV, products with multi-photo upload, collections, settings, backup
- Auto caption: 4 tones (premium, offer, festive, casual), English + Bangla product text, Facebook post (BN + EN), Instagram caption, Google title/description. Works free with a Google Gemini key, or with built-in templates
